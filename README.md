# STUDIO.ARC — 리퀴드 글래스 게임 & 프로그램 쇼케이스

Apple Liquid Glass 스타일의 반투명 유리 질감과 물방울처럼 부드럽게 펼쳐지는 모션, 다크 네온 쇼케이스 테마가 결합된 홍보 웹사이트입니다.

## 주요 기능
- **리퀴드 글래스 UI**: 다층 반투명 블러(`backdrop-filter`), 마우스 커서를 따라가는 유리 스페큘러 반사광, 물방울처럼 쫀득하게 이동하는 카테고리 필터 필.
- **물방울 확장 모달 & 영상 자동 재생**: 카드를 클릭하면 해당 카드 위치에서 물방울처럼 부드럽게 펼쳐지며 소개 영상이 즉시 자동 재생됩니다.
- **카테고리 필터 및 실시간 검색**: 전체 / 게임 / 프로그램 / 웹앱 필터 및 제목·설명·태그 검색을 지원합니다.
- **빌드 없는 순수 정적 사이트**: `index.html`을 브라우저로 열거나 GitHub Pages / Netlify / Vercel에 바로 배포할 수 있습니다.

## 내 게임/프로그램 추가하기
`projects.js` 파일의 `PROJECTS` 배열에 항목을 추가하거나 수정하면 즉시 반영됩니다.

- **로컬 동영상(`.mp4` / `.webm`) 사용 시**:
  `videos/` 폴더에 영상을 넣고 `videoUrl: "./videos/gameplay.mp4"` 처럼 경로를 지정하세요.
- **유튜브 영상 사용 시**:
  `videoUrl: "https://www.youtube.com/watch?v=영상ID"` 를 입력하면 모달에서 자동 재생됩니다.
- **영상을 아직 준비하지 않았을 때**:
  `videoUrl: ""` 로 비워두면 `demoPreset`에 맞춘 실시간 데모 영상이 자동 재생됩니다.
